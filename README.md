# Интерактивная лаборатория ИИ-резистентных учебных заданий (AI-Resistant Informatics Lab)

Веб-приложение и интерактивная обучающая среда для выполнения ИИ-резистентных рабочих листов и пошаговой визуализации работы интерпретатора Python на уроках информатики в 7-9 классах.

---

## 🌟 Ключевые возможности

1. **Интерактивные рабочие листы (7-9 классы, 3-я четверть):**
   - Полное соответствие Типовой учебной программе (ТУП РК) и критериальному оцениванию.
   - Интерактивная ручная трассировка ветвлений и циклов с автоматической проверкой гипотез.
   - Направленная отладка кода (дебаггинг): выявление дефектов типов данных (`TypeError`), выхода за границы списков (`IndexError`) и зацикливаний (`while True`).
   - Дидактические ограничения синтаксиса: автоматический валидатор запрещенных языковых конструкций (`max()`, `and`, `sum()`, срезы списков).
   - Экспертный аудит решений генеративного ИИ (ChatGPT) учащимися.
   - Рубрика формативного оценивания на 10 баллов с автоматическим расчетом дескрипторов и лист рефлексии («Светофор»).

2. **Пошаговый визуализатор работы интерпретатора (RAM Shelves):**
   - Собственная виртуальная машина Python на чистом JavaScript (ES Modules, без Node/Webpack/Vite на клиенте).
   - Визуальные полочки памяти с типами данных (`int`, `str`, `list`, `bool`), индексами элементов и подсветкой обновленных ячеек.
   - Плеер выполнения: пошаговый переход вперед/назад, автовоспроизведение, слайдер таймлайна, регулировка скорости (0.5x - 2.0x).
   - Педагогические объяснения каждого шага алгоритма простым и доступным школьникам языком.

3. **Динамический импорт и экспорт рабочих листов:**
   - **Никакого хардкода:** рабочие листы не зашиты намертво в кодовую базу.
   - Поддержка импорта новых заданий учителем через Drag & Drop JSON-файлов или текстовую вставку.
   - Автоматическая валидация по спецификации (`WorksheetParser`) с проверкой обязательных полей и суммы баллов рубрики (10 баллов).
   - Экспорт любого рабочего листа в JSON для обмена с коллегами.
   - Персистентное сохранение в `localStorage` браузера.

4. **Академичный дизайн по стандарту `unslop`:**
   - Спокойная нейтральная палитра (Slate/Zinc), высокая контрастность для проекторов и интерактивных досок.
   - Полное отсутствие нейросетевых клише: никаких неоновых фиолетовых градиентов, свечений и эмодзи-шума.
   - Поддержка печати (`Ctrl + P`) с автоматической оптимизацией макета в аккуратный бумажный лист А4.

## 🚀 Запуск и тестирование локально

Веб-приложение полностью статическое и не требует установки тяжелых зависимостей.

### 1. Запуск юнит-тестов (все 22 теста):
```bash
node --test tests/*.test.js
```

### 2. Локальный запуск в браузере:
```bash
# В директории ai-resistant-lab:
python3 -m http.server 8000
```
После запуска откройте в браузере: `http://localhost:8000`

## 🌐 Развертывание на GitHub Pages

Репозиторий настроен как независимый Git-проект, готовый к публикации на GitHub Pages:

1. Создайте новый публичный репозиторий на GitHub (например, `ai-resistant-lab`).
2. В терминале в папке `ai-resistant-lab` выполните:
```bash
git add .
git commit -m "Initial release: AI-Resistant Informatics Lab"
git branch -M main
git remote add origin https://github.com/<ваш_аккаунт>/ai-resistant-lab.git
git push -u origin main
```
3. В настройках репозитория на GitHub перейдите в **Settings** -> **Pages**.
4. В разделе **Build and deployment** выберите:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main` / `/ (root)`
5. Нажмите **Save**. Через 1-2 минуты сайт станет доступен по адресу:
   `https://<ваш_аккаунт>.github.io/ai-resistant-lab/`

## ✍️ Создание и импорт собственных рабочих листов

1. Нажмите кнопку **«Импорт»** в шапке приложения.
2. Скачайте эталонный шаблон, нажав **«Скачать шаблон (.json)»** (или используйте файл `templates/worksheet_template.json`).
3. Заполните поля урока, условия задач и дескрипторы (подробная документация в [docs/WORKSHEET_SPEC.md](docs/WORKSHEET_SPEC.md)).
4. Перетащите готовый файл обратно в окно импорта. Система автоматически проверит корректность баллов и добавит лист в список доступных материалов.
