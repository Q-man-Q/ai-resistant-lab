# AI-Resistant Informatics Lab

Интерактивная обучающая веб-среда для выполнения ИИ-резистентных заданий и пошаговой визуализации работы интерпретатора Python на уроках школьной информатики.

Разработано в рамках дипломной работы по теме:  
**«Разработка и апробация методики применения ИИ-резистентных учебных заданий при обучении школьной информатике»**.

## Онлайн-версия
Приложение доступно онлайн на GitHub Pages:  
👉 **[https://q-man-q.github.io/ai-resistant-lab/](https://q-man-q.github.io/ai-resistant-lab/)**

## Локальный запуск
Приложение полностью статическое и не требует установки сборщиков или пакетов:

```bash
# Запуск локального сервера
python3 -m http.server 8000

# Запуск модульных тестов ядра интерпретатора
node --test tests/*.test.js
```
